【这一版改了什么】
1. 应用图标恢复纯白：删除「彩色块上自动把图标染成深蓝黑」的脚本
   （含每 1.5 秒遍历 + 全子树 MutationObserver），并去掉深色描边。
   三主题实测 9 个图标均为 rgb(255,255,255)、filter:none。
   顺带修掉通知里指向不存在的 ./icons/ 目录。
2. 舒尔特按宫格拆排行：成绩卡里 3×3 / 4×4 / 5×5 / 6×6 四个最佳成绩格子
   现在各自可点，点哪个进哪个宫格的排行；排行页顶部还能再切宫格与
   数字/倒序/字母模式。总览、分位线、前 20、全部历史、单条删除+确认都在。
   不再把 3×3 和 6×6 混在一起按秒数排序。
3. 版本号统一：关于弹窗不再写死 v3.0，改接 APP_VER；
   关于页、设置项、云同步面板、manifest、sw 全部对齐到同一版本。
4. sw.js 重写：缓存名写死 lumen-v41（不再靠 manifest.version 动态取名，
   避免 SW 重启后缓存名漂移）；核心资源与可选图标分开逐个缓存；
   activate 只清 lumen- 前缀的旧缓存。
5. 补齐 6 个图标资源：深色渐变 + 白色晨昏月牙 + 暖金日点，
   含 maskable（满版安全区）与 apple-touch-icon（180px 不透明底）。
