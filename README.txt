晨昏 LUMEN  v3.2·b42  部署说明
=====================================

【这版改了什么】
基于 v41 原地修改，只动 index.html / manifest.json / sw.js，图标文件与 v41 完全相同。

1. 便签日历
   - 每个日期格都有可见边框与底色，整月不再连成一片；外层加圆角边框
   - 点任意日期有渐变选中高亮（之前点完没反馈）
   - 有便签 / 有提醒的小圆点加大、加描边
   - 当天便签逐条分格：独立卡片 + 左侧色条 + 标题 / 摘要 / 时间行
   - 「这天没有便签」从一行灰字改成虚线空态卡片
   - 月份切换按钮收成小圆角；顶部「今天」不再折成两行
   - 日期标题去掉与「（N）」重复的「共 N 条」

2. 新建 / 编辑便签
   - 根因：#neTitle 被写成 sticky top:44px，与正文卡片重叠 36px，标题压在正文上
   - 现改为「标题 / 正文 / 底部操作」三段分区，实测零重叠（间距 8px）
   - 正文 placeholder 正常显示，写长文时标题不位移、不遮挡
   - 正文右侧留 60px，右下四个工具按钮不再压住文字；按钮收进半透明圆角工具组
   - 编辑已有便签时「保存并返回」仍在屏内可点，不需要滚动找按钮
   - 修掉 iPad 下保存按钮撑出屏幕 32px 的横向溢出

3. 同类视觉统一
   - 扫过 4 个主页面 + 9 个子应用 + 便签列表/日历/编辑页，三主题
   - 真问题只有上面两处；工具箱顶部说明文字也统一成淡提示条

【上传清单】
把这 3 个文件覆盖到 GitHub 仓库 yhx-wt/lumen 根目录即可：
  index.html
  sw.js
  manifest.json
（6 个图标 v41 已传过，不用再动；若仓库里没有图标，请把包里 6 个 png/svg 一起传）

【验收】
- 关于页 / 云同步面板显示 v3.2·b42
- 便签日历：每个日期都有格子；点日期变色；下方便签一条一张卡片
- 新建便签：标题在上、正文在下，中间不重叠；输入长文标题不动
- 若打开还是旧样子：Cloudflare 后台 → 该站点 → Caching → Purge Everything，再刷新
