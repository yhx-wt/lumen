晨昏 LUMEN  v3.2·b43  部署说明
=====================================

基于 v42 原地修改，只动 index.html / manifest.json / sw.js，6 个图标文件不变。

【这版改了什么】舒尔特
1. 每局结果
   - 新增「击败 X%（a/b）」：a = 本局在同宫格 + 同模式里的名次，b = 该组合总次数（含本局）
   - 只在同一宫格 + 同一模式内比较，3×3 与 6×6 不混排，口径与排行页一致
   - 五档颜色 / 图标 / 文案 + 同步进度条：
       ≥90% 金 🔥 碾压全场 ｜ ≥70% 绿 ⚡ 状态很好 ｜ ≥40% 主色 👍 中上水平
       ≥15% 青 🌱 稳步上升 ｜ 其余 灰 💪 继续加油
   - 破纪录单独样式：🏆「破纪录！击败 100%（1/N）」+ 金色渐变卡 + 彩带
   - 首局：显示（1/1），注明「下局起开始对比」，不会假装有击败率
   - 成绩从 0.1″ 改到 0.01″（百分位），棋盘倒计时同步两位小数
   - 历史保留从 60 局放宽到 300 局，让 b 更接近真实总次数

2. 排行榜
   - 最下面「全部记录」改为按产生时间倒序（最新在前），与上面「前 20 名 · 按成绩」不再重复
   - 记录时间从「26年10月18日 23:18」精确到「26年10月18日 23:18:04.37」（秒 + 百分秒）
   - 前 20 / 分位线 / 总览 / 删除确认，成绩全部两位小数

  index.html
